# cloud-infra-learning

AWS・Linux・Terraformを学習し、クラウドインフラエンジニアを目指すための学習記録です。

## 目的

クラウドインフラの基礎から実践までを学び、将来的にゲームサービスを支えるインフラエンジニア／SREを目指します。

## 学習テーマ

- Linux：基本コマンド、ユーザー・権限、プロセス
- ネットワーク：TCP/IP、DNS、HTTP/HTTPS、ポート
- AWS：IAM、EC2、S3、VPC、CloudWatch
- IaC：Terraform
- 自動化・運用：Python、シェルスクリプト、監視、障害対応

## 学習方針

- 週10時間を目安に継続する
- まずは基礎を理解し、小さな手順を実際に試す
- 学んだ内容は自分の言葉で説明できる形にまとめる
- AWSを利用するときはMFAと予算アラートを設定し、不要なリソースを削除する
- 個人学習で作成したものは、商用サービスでの実務経験と混同しない

## 次回の学習

Linux基礎の第1項目「Linuxとは何か」から開始する。

学習予定（目安4〜5時間）：

1. Linuxとは何か、OS・サーバーとの関係
2. ディレクトリ・ファイル構造
3. 基本操作：`pwd`、`ls`、`cd`
4. ファイル操作：`cp`、`mv`、`rm`、`cat`
